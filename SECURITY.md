# Politique de sécurité

CADSurfaceAnalyser lit des fichiers STEP et écrit des fichiers à côté d'eux ; il n'ouvre
aucune connexion réseau.

## Signaler une vulnérabilité

Merci de **ne pas** ouvrir de ticket public pour un problème de sécurité. Utilisez le
signalement privé de GitHub (onglet *Security* → *Report a vulnerability*) si cette
fonction est activée sur le dépôt, ou contactez le mainteneur directement.

Indiquez la version, le système, et si possible un fichier STEP minimal qui reproduit
le problème (sans donnée confidentielle).

## Versions prises en charge

Seule la dernière version publiée reçoit des corrections.
